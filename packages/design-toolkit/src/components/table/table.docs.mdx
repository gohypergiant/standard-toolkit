# Table

Configurable data table with sorting, selection, and row actions built on TanStack React Table.

```tsx
import { createColumnHelper } from '@tanstack/react-table';

type Person = {
  id: string;
  firstName: string;
  lastName: string;
};

const columnHelper = createColumnHelper<Person>();

const columns = [
  columnHelper.accessor('firstName', {
    id: 'firstName',
    cell: (info) => info.getValue(),
    header: () => <span>First Name</span>,
  }),
  columnHelper.accessor('lastName', {
    id: 'lastName',
    cell: (info) => <i>{info.getValue()}</i>,
    header: () => <span>Last Name</span>,
  }),
];

const data = [
  { id: 'tanner', firstName: 'Tanner', lastName: 'Linsley' },
  { id: 'joe', firstName: 'Joe', lastName: 'Dirte' },
];

<Table columns={columns} data={data} showCheckbox />
```

## Controlled and Uncontrolled State

Sorting, row selection, and row pinning each follow the same convention: the
state is uncontrolled by default, can be seeded with a `default*` prop, and
becomes controlled when the value prop is set. Every `on*Change` callback
receives the plain next state value, ready to pass to a `useState` setter. A
controlled value without a matching callback stays frozen at that value.

The state types (`SortingState`, `RowSelectionState`, `RowPinningState`) are
imported from `@tanstack/react-table`; the design toolkit does not re-export
them.

## Static Table

For simple tables without sorting or selection, use subcomponents directly.

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHeaderCell>First Name</TableHeaderCell>
      <TableHeaderCell>Last Name</TableHeaderCell>
    </TableRow>
  </TableHeader>
  <TableBody>
    {data.map((person) => (
      <TableRow key={person.id}>
        <TableCell>{person.firstName}</TableCell>
        <TableCell>{person.lastName}</TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>
```

## Column Sizing

Define a `size` property in column definitions to set fixed widths.

```tsx
columnHelper.accessor('firstName', {
  id: 'firstName',
  header: 'First Name',
  size: 150, // Width in pixels
})
```

## Sorting

Use the column header menu (kebab) to sort ascending, sort descending, or
clear sorting. Sorting is uncontrolled by default; seed the initial order with
`defaultSort`, or control it with `sort` and `onSortChange`.

```tsx
import type { SortingState } from '@tanstack/react-table';

const [sort, setSort] = useState<SortingState>([{ id: 'age', desc: true }]);

<Table
  columns={columns}
  data={data}
  sort={sort}
  onSortChange={setSort}
/>
```

`onSortChange` receives the plain next `SortingState`: `[{ id, desc }]`, or
`[]` when sorting is cleared. The header menu writes at most one entry (no
multi-column sort).

### Server-side Sorting

Set `manualSorting` to sort the data yourself (for example on the server). The
table renders `data` in the order you provide and still reflects the
controlled `sort` value in the header menu and `aria-sort` attributes.

```tsx
import type { SortingState } from '@tanstack/react-table';

const [sort, setSort] = useState<SortingState>([]);

// Sort wherever the data lives, using sort[0]?.id and sort[0]?.desc
const sortedData = useSortedFromServer(sort[0]);

<Table
  columns={columns}
  data={sortedData}
  manualSorting
  sort={sort}
  onSortChange={setSort}
/>
```

## Row Selection

Row selection is uncontrolled by default. Seed it with `defaultRowSelection`,
or control it with `rowSelection` and `onRowSelectionChange`.

```tsx
import type { RowSelectionState } from '@tanstack/react-table';

// Uncontrolled: seed the initial selection
<Table
  columns={columns}
  data={data}
  showCheckbox
  defaultRowSelection={{ tanner: true, joe: true }}
/>

// Controlled: hold the state yourself
const [rowSelection, setRowSelection] = useState<RowSelectionState>({});

<Table
  columns={columns}
  data={data}
  showCheckbox
  rowSelection={rowSelection}
  onRowSelectionChange={setRowSelection}
/>
```

`onRowSelectionChange` receives the plain next `RowSelectionState`: an object
mapping selected row IDs to `true`, such as `{ tanner: true }`.

## Row Pinning

Pin rows to the top or bottom of the table through the row actions menu. Row
pinning is uncontrolled by default; seed it with `defaultRowPinning`, or
control it with `rowPinning` and `onRowPinningChange`. Pinned IDs absent from
`data` are skipped when rendering, never pruned; the controlling owner is
responsible for removing stale IDs.

```tsx
import type { RowPinningState } from '@tanstack/react-table';

const [rowPinning, setRowPinning] = useState<RowPinningState>({
  top: ['joe'],
  bottom: [],
});

<Table
  columns={columns}
  data={data}
  rowPinning={rowPinning}
  onRowPinningChange={setRowPinning}
/>
```

## Pagination

Table handles client-side data slicing internally when `pageSize` is set. Render `<Pagination>` alongside the Table to provide page navigation - the two components are kept separate so you have full control over Pagination's placement and props.

```tsx
const [page, setPage] = useState(1);

<Table columns={columns} data={data} pageSize={10} page={page} onPageChange={setPage} />
<Pagination value={page} total={Math.ceil(data.length / 10)} onChange={setPage} />
```

<Canvas of={TableStories.ClientSidePagination} />

### Server-side Pagination

For server-side (pre-paginated) data, manage page state externally and pass only the current page's data. The Table reflects `data` prop changes directly.

```tsx
const [page, setPage] = useState(1);
const pageData = allData.slice((page - 1) * PAGE_SIZE, page * PAGE_SIZE);

<Table columns={columns} data={pageData} />
<Pagination value={page} total={totalPages} onChange={setPage} />
```

## Props

`SortingState`, `RowSelectionState`, and `RowPinningState` are imported from `@tanstack/react-table`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `columns` | `ColumnDef[]` | - | Array of TanStack column definitions |
| `data` | `T[]` | - | Array of data objects with `id` property |
| `showCheckbox` | `boolean` | - | Show checkbox column for row selection |
| `rowSelection` | `RowSelectionState` | - | Controlled row selection state (object mapping selected row IDs to `true`) |
| `defaultRowSelection` | `RowSelectionState` | `{}` | Initial row selection for uncontrolled use; ignored while `rowSelection` is set |
| `onRowSelectionChange` | `(rowSelection: RowSelectionState) => void` | - | Called with the plain next selection state |
| `sort` | `SortingState` | - | Controlled sort state, e.g. `[{ id: 'age', desc: true }]` |
| `defaultSort` | `SortingState` | `[]` | Initial sort for uncontrolled use; ignored while `sort` is set |
| `onSortChange` | `(sort: SortingState) => void` | - | Called with the plain next sort state, in both client-side and `manualSorting` modes |
| `rowPinning` | `RowPinningState` | - | Controlled row pinning state, e.g. `{ top: ['row-1'], bottom: [] }` |
| `defaultRowPinning` | `RowPinningState` | `{ top: [], bottom: [] }` | Initial row pinning for uncontrolled use; ignored while `rowPinning` is set |
| `onRowPinningChange` | `(rowPinning: RowPinningState) => void` | - | Called with the plain next pinning state |
| `kebabPosition` | `'left' \| 'right'` | `'right'` | Position of row action menu |
| `persistHeaderKebabMenu` | `boolean` | `true` | Always show header kebab menu |
| `persistRowKebabMenu` | `boolean` | `true` | Always show row kebab menu |
| `persistNumerals` | `boolean` | `false` | Always show row numbers |
| `enableSorting` | `boolean` | `true` | Enable column sorting |
| `enableColumnReordering` | `boolean` | `true` | Enable column reordering |
| `enableRowActions` | `boolean` | `true` | Enable row action menu |
| `manualSorting` | `boolean` | `false` | Server-side sorting mode; data renders in the order provided |
| `onColumnReorderChange` | `(index) => void` | - | Callback when column is reordered |
| `fullWidth` | `boolean` | `false` | Apply full width with fixed layout |
| `pageSize` | `number` | - | Rows per page; enables built-in pagination |
| `page` | `number` | - | Controlled current page (1-indexed) |
| `defaultPage` | `number` | `1` | Uncontrolled default page (1-indexed) |
| `onPageChange` | `(page: number) => void` | - | Callback when page changes |

## Subcomponents

For static tables, use these subcomponents:

| Component | Description |
|-----------|-------------|
| `TableHeader` | Renders `<thead>` section |
| `TableHeaderCell` | Individual header cell `<th>` |
| `TableBody` | Renders `<tbody>` section |
| `TableRow` | Table row `<tr>` |
| `TableCell` | Data cell `<td>` |

## Accessibility

- Sorting is performed from each column's header menu (kebab), with Sort Ascending, Sort Descending, and Clear Sort items reachable by keyboard
- ARIA sort attributes on sortable columns
- Keyboard navigation for row actions
- Screen reader support for selection state
