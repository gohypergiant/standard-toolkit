"@accelint/map-toolkit": minor
---

- Add bearing/distance measurement tools: `MeasurementLayer`, `useMeasurement`, and `MeasurementTool`, exported from `@accelint/map-toolkit/deckgl/measurement-layer` (not part of the `deckgl` barrel).
- **`MeasurementLayer`** is a deck.gl `CompositeLayer` that renders a dashed line with circular endpoints and an optional text label. The destination is unwrapped relative to the origin so a segment that crosses the antimeridian draws the short way around, and the label sits on that unwrapped path (the geodesic midpoint from `midpoint()` in `@accelint/geo/geodesy`, then unwrapped relative to the origin), so asymmetric antimeridian crossings keep the label on the line. Points that are not finite `[longitude, latitude]` tuples render nothing. A `units` array with zero or more than two entries falls back to the default `['kilometers', 'nauticalmiles']` pair; the layer never throws inside `renderLayers`. Declares `color`-typed `defaultProps` for `lineColor` / `endpointColor` so deck.gl diffs the colors by value.
- **`useMeasurement(mapId?, requiresModifier?)`** is a React hook that returns `{ isMeasuring, pointA, pointB, distanceMeters, bearingDeg, start, clear }`. Format the readout with `formatDistance(distanceMeters, units)` and `formatBearing(bearingDeg)` from `@accelint/formatters/bearing`. Non-finite points yield zeros rather than throwing. `start(pointA)` restarts a measurement from a coordinate (resets `pointB`, emits `measurement:start`, and suppresses pan). Releasing the required modifier mid-drag completes the measurement at the last captured point.
- **`measurementStore`** owns the `map:dragStart` / `map:drag` / `map:dragEnd` subscription once per map, so `measurement:start` / `measurement:update` / `measurement:complete` / `measurement:clear` and the `map:disablePan` / `map:enablePan` toggles fire once regardless of how many `useMeasurement` instances are mounted. `requiresModifier` is per-map state set by the hook; when two hooks on one map pass different values, the most recently mounted wins. `measurement:update` fires on every drag move. `complete()` with no `pointB` behaves like `clear()`, and `measurement:complete` carries a `MeasurementCompletePayload` with a non-null `pointB`. When the last subscriber for a map unmounts mid-drag, the measurement is finished and map pan is restored.
- **`MeasurementTool`** is a convenience component that composes the hook and layer. Drop `<MeasurementTool />` inside a `<BaseMap>` to add drag-to-measure functionality with zero additional wiring. Supports `requiresModifier` (`'shift' | 'alt'`) to allow plain drag to continue panning while a modifier key activates measurement. With `'shift'`, the hook emits `map:disableZoom` while Shift is held so BaseMap's Shift+drag zoom (box zoom or rubber-band zoom) does not compete, and `map:enableZoom` on release. `'ctrl'` is deliberately not an option: Ctrl+drag is BaseMap's rotate/tilt gesture, and tilt gestures emit no drag events, so it could never activate. `MeasurementToolProps` is exported for consumers wrapping the component.
- Fiber registration (`import '@accelint/map-toolkit/deckgl/measurement-layer/fiber'`) enables JSX usage: `<measurementLayer pointA={…} pointB={…} />`.
- The measurement entry point also exports the `MeasurementToolProps`, `RequiresModifier`, `MeasurementCompletePayload`, `MeasurementClearEvent`, and `MeasurementClearPayload` types.
- Add `dragStart`, `drag`, and `dragEnd` events to `MapEvents` and `BaseMap`. `map:dragStart` and `map:drag` carry a `MapDragPayload` with a finite `coordinate` and are skipped off the globe; tilt/rotate gestures (right-drag, Ctrl + left-drag) emit no drag events at all; `map:dragEnd` is always emitted and carries a `MapDragEndPayload` whose `coordinate` is `[number, number] | null`. All five types (`MapDragPayload`, `MapDragEndPayload`, `MapDragStartEvent`, `MapDragEvent`, `MapDragEndEvent`) are exported from `@accelint/map-toolkit/deckgl`.
- Add the `@accelint/map-toolkit/shared/coordinates` subpath exporting the `isLonLatTuple` type guard, which narrows a `number[]` to a finite `[longitude, latitude]` tuple.
- **Migration:** `@accelint/geo` and `@accelint/formatters` are now required peer dependencies. Install both alongside `@accelint/map-toolkit`: `pnpm add @accelint/geo @accelint/formatters`.
- `getViewportSize` now divides by the exact `METERS_PER_UNIT` factors from `@accelint/constants/units` instead of multiplying by truncated constants, so feet, miles, and nautical-mile readouts can differ from previous versions in the last digits.
- Fix BaseMap's deck picking viewport freezing at the initial frame. BaseMap no longer passes `onLoad` to the deck overlay: the overlay wraps `onLoad` to install its map-move listener and re-sends every prop on each update, so an `onLoad` among them could overwrite the wrapper before deck initialized, leaving `info.coordinate` unprojected against a stale view after any pan or zoom. BaseMap's load work and a consumer `onLoad` now run from MapLibre's `load` event.
- `map:disableZoom` / `map:enableZoom` now restore only what was configured: native box zoom is re-enabled only when BaseMap has it on (it is off while `enableRbz` is set), double-click zoom is no longer touched (BaseMap locks it off), and the rubber-band zoom handler stops listening for Shift while zoom is disabled instead of being disarmed once. This makes `useShiftZoomDisable` reliable for the draw and edit shape layers as well.
- `RbzHandler` gains `isListening()` and ignores key-repeat Shift keydowns.
- Grid-layer click handling accepts 3-element `[longitude, latitude, z]` coordinates (deck.gl yields these when any layer is `pickable: '3d'`) by validating only the first two entries, so grid cell clicks are not dropped in 3D views.
