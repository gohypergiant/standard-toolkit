# Map Toolkit

Map Toolkit provides comprehensive geospatial functionality including coordinate systems, projections, and utilities for building mapping applications.

## Installation

```bash
pnpm add @hypergiant/map-toolkit
```

## Features

- Multiple coordinate system support (Geographic, UTM, MGRS, USNG)
- Coordinate transformations and projections
- Geospatial calculations (distance, bearing, area)
- GeoJSON utilities
- Tile layer management
- Full TypeScript support
