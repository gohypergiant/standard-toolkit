# Design Toolkit

Design Toolkit is a React component library built on React Aria, providing accessible, customizable components for modern web applications.

## Installation

```bash
pnpm add @hypergiant/design-toolkit
```

## Features

- Built on React Aria for best-in-class accessibility
- Comprehensive component library (buttons, forms, overlays, collections)
- Full TypeScript support with detailed type definitions
- Composable architecture for maximum flexibility
- Integration with design-foundation tokens
