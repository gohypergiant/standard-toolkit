# Prettier Config

Shared Prettier configuration for consistent code formatting across projects.

## Installation

```bash
pnpm add -D @accelint/prettier-config
```

## Usage

Reference this configuration in your `package.json`:

```json
{
  "prettier": "@accelint/prettier-config"
}
```

## Features

- Opinionated formatting rules
- Consistent indentation and line length
- Automatic semicolon and quote management
- Support for TypeScript, JSON, and Markdown
