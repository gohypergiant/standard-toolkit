# ESLint Config

Shared ESLint configuration for TypeScript and React projects with opinionated rules for code quality.

## Installation

```bash
pnpm add -D @accelint/eslint-config
```

## Usage

Extend this configuration in your `.eslintrc.json`:

```json
{
  "extends": ["@accelint/eslint-config"]
}
```

## Features

- TypeScript linting rules
- React and React Hooks rules
- Import sorting and organization
- Accessibility rules for React components
