# PostCSS Tailwind CSS Modules

A PostCSS plugin that enables using Tailwind CSS utilities within CSS Modules.

## Installation

```bash
pnpm add -D @accelint/postcss-tailwind-css-modules
```

## Features

- Tailwind CSS integration with CSS Modules
- Automatic utility class composition
- Type-safe class names with TypeScript
- Build-time optimization
