# Smeegl

Monorepo management utilities for pnpm workspaces with tools for workspace operations and dependency management.

## Installation

```bash
pnpm add -D @accelint/smeegl
```

## Features

- Workspace dependency analysis
- Package graph visualization
- Dependency update utilities
- Workspace command execution
