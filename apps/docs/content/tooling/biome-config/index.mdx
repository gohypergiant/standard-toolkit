# Biome Config

Shared Biome configuration for consistent linting and formatting across projects.

## Installation

```bash
pnpm add -D @accelint/biome-config
```

## Usage

Extend this configuration in your `biome.json`:

```json
{
  "extends": ["@accelint/biome-config"]
}
```

## Features

- TypeScript and JavaScript linting rules
- Consistent formatting configuration
- Import sorting and organization
- React-specific rules
