## Installation

```bash
pnpm add -D @accelint/biome-config
```

```bash
npm install --save-dev @accelint/biome-config
```

```bash
yarn add -D @accelint/biome-config
```

## Usage

### Complete Configuration

Import all configuration presets in your `biome.json`:

```json
{
  "$schema": "https://biomejs.dev/schemas/2.3.8/schema.json",
  "extends": [
    "@accelint/biome-config/linter",
    "@accelint/biome-config/formatter",
    "@accelint/biome-config/analyzer"
  ]
}
```

### Selective Import

Import only the presets you need:

```json
{
  "$schema": "https://biomejs.dev/schemas/2.3.8/schema.json",
  "extends": ["@accelint/biome-config/linter"]
}
```

## Available Configurations

### Linter

### Formatter

See [Formatter Configuration](./formatter) for details.

### Analyzer

Code analysis settings for import organization and better maintainability.

See [Analyzer Configuration](./analyzer) for details.

## Customization

Override any rule in your project's `biome.json`:

```json
{
  "extends": ["@accelint/biome-config/linter"],
  "linter": {
    "rules": {
      "complexity": {
        "noExcessiveCognitiveComplexity": {
          "options": {
            "maxAllowedComplexity": 20
          }
        }
      }
    }
  }
}
```

## Scripts

Add these scripts to your `package.json`:

```json
{
  "scripts": {
    "lint": "biome lint .",
    "lint:fix": "biome lint --write .",
    "format": "biome format --write .",
    "format:check": "biome format .",
    "check": "biome check --write ."
  }
}
```

## Editor Integration

### VSCode

Install the [Biome VSCode extension](https://marketplace.visualstudio.com/items?itemName=biomejs.biome):

```json
{
  "editor.defaultFormatter": "biomejs.biome",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "quickfix.biome": "explicit"
  }
}
```

### Other Editors

See [Biome editor integrations](https://biomejs.dev/guides/integrate-in-editor/) for setup instructions.
