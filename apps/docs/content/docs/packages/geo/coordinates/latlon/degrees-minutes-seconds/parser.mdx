## Usage

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

// Parse with explicit format
const [tokens, errors] = parseDegreesMinutesSeconds('LATLON', '37° 46\' 29.64" N / 122° 25\' 9.84" W');
// tokens: ['37', '46', '29.64', 'N', '/', '122', '25', '9.84', 'W']
// errors: []
```

## Reference

```typescript
function parseDegreesMinutesSeconds(
  format: 'LATLON' | 'LONLAT',
  input: string
): [tokens: string[], errors: string[]]
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `format` | `'LATLON' \| 'LONLAT'` | Expected format ordering |
| `input` | `string` | Raw coordinate string to parse |

### Returns

Returns a tuple containing:
- `tokens`: Array of parsed coordinate components (degrees, minutes, seconds, bearings, dividers)
- `errors`: Array of validation error messages (empty if valid)

### Validation Rules

Validates that:
- Degree values are integers (no decimal component allowed in degrees)
- Minute values are integers in valid range (0-59)
- Second values are in valid range (0-59.999...)
- Bearing indicators match the specified format (N/S for latitude, E/W for longitude)
- Negative signs on degrees are converted to appropriate bearing directions

## Examples

### Example: Basic parsing

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

const [tokens, errors] = parseDegreesMinutesSeconds('LATLON', '37° 46\' 29.64" N / 122° 25\' 9.84" W');
// tokens: ['37', '46', '29.64', 'N', '/', '122', '25', '9.84', 'W']
// errors: []
```

### Example: Without degree/minute/second symbols

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

const [tokens, errors] = parseDegreesMinutesSeconds('LATLON', '45 30 15.23 N, 122 25 9.84 W');
// tokens: ['45', '30', '15.23', 'N', '/', '122', '25', '9.84', 'W']
// errors: []
```

### Example: Maximum valid values

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

const [tokens, errors] = parseDegreesMinutesSeconds('LATLON', '90° 0\' 0" S, 180° 0\' 0" W');
// tokens: ['90', '0', '0', 'S', '/', '180', '0', '0', 'W']
// errors: []
```

### Example: Negative values convert to bearings

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

const [tokens, errors] = parseDegreesMinutesSeconds('LATLON', '-40 26 30 / 79 58 15');
// tokens: ['40', '26', '30', 'S', '/', '79', '58', '15', 'E']
// errors: []
```

### Example: LONLAT format

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

const [tokens, errors] = parseDegreesMinutesSeconds('LONLAT', '122° 25\' 9.84" W / 37° 46\' 29.64" N');
// tokens: ['122', '25', '9.84', 'W', '/', '37', '46', '29.64', 'N']
// errors: []
```

### Example: Seconds out of range

### Example: Minutes out of range


### Example: Decimal degrees value error

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

const [tokens, errors] = parseDegreesMinutesSeconds('LATLON', '40.5° 26\' 30" N, 79° 58\' 0" W');
// tokens: []
// errors: ['[ERROR] Degrees value (40.5) must not include decimal value.']
```

### Example: Flexible separators

```typescript
import { parseDegreesMinutesSeconds } from '@accelint/geo';

// Comma separator
parseDegreesMinutesSeconds('LATLON', '40° 26\' 30" N, 79° 58\' 0" W');

// Slash separator
parseDegreesMinutesSeconds('LATLON', '40° 26\' 30" N / 79° 58\' 0" W');

// Space separator
parseDegreesMinutesSeconds('LATLON', '40° 26\' 30" N 79° 58\' 0" W');
```

> **Good to know:** The parser accepts various separators (comma, slash, or space) between coordinate components. Negative signs on degrees are automatically converted to appropriate bearing directions (S for negative latitude, W for negative longitude).

> **Good to know:** Degrees Minutes Seconds format requires integer degrees and integer minutes. Only seconds may contain decimal values. Use `parseDecimalDegrees` for decimal degree values or `parseDegreesDecimalMinutes` for DDM notation.
