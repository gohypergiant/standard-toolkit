Parses Universal Transverse Mercator (UTM) coordinate strings and converts them to latitude/longitude decimal degrees with detailed validation.

## Usage

```typescript
import { parseUTM } from '@accelint/geo';

// Parse UTM coordinate
const [coords, errors] = parseUTM(null, '18 N 585628 4511322');
// coords: ['40.74839601188732', 'N', '/', '73.98570490632135', 'W']
// errors: []
```

## Reference

```typescript
function parseUTM(
  _format: any,
  input: string
): [tokens: string[], errors: string[]]
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `_format` | `any` | Unused format parameter (kept for interface compatibility) |
| `input` | `string` | UTM coordinate string to parse (e.g., '18 N 585628 4511322') |

### Returns

Returns a tuple containing:
- `tokens`: Array with latitude/longitude values and bearing indicators
- `errors`: Array of validation error messages (empty if valid)

### UTM Format

UTM coordinates consist of:
1. **Zone Number** (1-60): UTM longitudinal zone
2. **Hemisphere** (N or S): North or South hemisphere
3. **Easting** (0-999999): Meters east from zone's central meridian
4. **Northing** (0-9999999): Meters north from equator (N) or south from 10,000km (S)

Expected format: `ZZ N|S EEEEE NNNNN`

Example: `18 N 585628 4511322`

### Validation Rules

Validates that:
- Zone number is between 1 and 60
- Hemisphere letter is N (North) or S (South)
- Easting is a valid non-negative number
- Northing is a valid non-negative number

> **Good to know:** UTM divides the Earth into 60 longitudinal zones, each 6° wide. Zone 1 starts at 180° West. The parser automatically normalizes input by ensuring proper spacing between zone and hemisphere.

> **Good to know:** UTM uses the geodesy library for conversion. The coordinate system handles zone-specific calculations and converts to precise latitude/longitude values.

> **Good to know:** The parser accepts both `18N` and `18 N` formats (with or without space between zone and hemisphere). Internally, it normalizes to the format expected by the geodesy library.
