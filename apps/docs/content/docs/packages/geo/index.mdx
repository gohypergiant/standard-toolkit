## Installation

```bash
pnpm add @accelint/geo
```

## Usage

```typescript
// Import coordinate utilities
import { createCoordinate, coordinateSystems } from '@accelint/geo';

// Import formatters and parsers
import { formatDecimalDegrees, parseDecimalDegrees } from '@accelint/geo';
import { parseMGRS, parseUTM } from '@accelint/geo';

// Import geodesy functions
import { bearing, distance, greatCirclePoints, midpoint } from '@accelint/geo/geodesy';
```

## Geodesy

Compute great-circle relationships between two `[longitude, latitude]` points on a spherical Earth. All geodesy functions take `LonLatTuple` values (GeoJSON order), which is the reverse of the `[latitude, longitude]` order used by `createCoordinate`.

- [bearing](./geodesy/bearing.md) - Initial bearing in degrees clockwise from true north, `[0, 360)`
- [distance](./geodesy/distance.md) - Distance in meters
- [midpoint](./geodesy/midpoint.md) - Midpoint along the shortest great-circle path
- [greatCirclePoints](./geodesy/great-circle-points.md) - Evenly spaced vertices along the path, with unwrapped longitudes for drawing
- [toSphericalPoints](./geodesy/to-spherical-points.md) - Shared validation step that returns `LatLonSpherical` points
