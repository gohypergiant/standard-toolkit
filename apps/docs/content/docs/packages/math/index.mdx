## Installation

```bash
pnpm add @accelint/math
```

## Usage

```typescript
// Import from root (all exports)
import { clamp, random, randomInt, round } from '@accelint/math';

// Import from sub-modules
import { clamp } from '@accelint/math/clamp';
import { random, randomInt } from '@accelint/math/random';
import { round } from '@accelint/math/round';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [clamp](./clamp) | Clamps a number within the specified bounds |
| [random](./random) | Generate random numbers and integers within specified bounds |
| [round](./round) | Rounds a number to a specified precision |
