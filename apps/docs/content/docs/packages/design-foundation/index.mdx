## Installation

```bash
pnpm add @accelint/design-foundation
```

## Usage

```typescript
// Import design tokens
import { tokens } from '@accelint/design-foundation/tokens';

// Import CSS utilities
import { css } from '@accelint/design-foundation/lib/css';
import { utils } from '@accelint/design-foundation/lib/utils';
```

```css
/* Import styles */
@import '@accelint/design-foundation/styles';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [tokens](./tokens/index.md) | Complete design token system including colors, typography, spacing, shadows, and animations |
| [lib/css](./lib/css.md) | CSS utilities and helpers |
| [lib/utils](./lib/utils.md) | JavaScript utility functions for design tokens |
| styles | Core CSS styles and variables |
