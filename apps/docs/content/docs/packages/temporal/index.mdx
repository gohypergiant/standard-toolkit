## Installation

```bash
pnpm add @accelint/temporal
```

## Usage

```typescript
// Import from root (all exports)
import { setClockInterval, setClockTimeout } from '@accelint/temporal';

// Import from sub-modules
import { setClockInterval, setClockTimeout } from '@accelint/temporal/timers';
import { remainder, callNextSecond } from '@accelint/temporal/timers/utils';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [timers](./timers/index.md) | setTimeout and setInterval replacements that align execution to clock boundaries |
| [timers/utils](./timers/utils.md) | Utility functions for temporal calculations and clock-aligned execution |
