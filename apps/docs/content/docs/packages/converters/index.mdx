## Installation

```bash
pnpm add @accelint/converters
```

## Usage

```typescript
// Import from root (all exports)
import { 
  hexToRgba255Tuple, 
  rgba255TupleToHex,
  booleanToNumber,
  toBoolean 
} from '@accelint/converters';

// Import from sub-modules
import { hexToRgba255Tuple } from '@accelint/converters/hex';
import { cssRgbaStringToRgba255Tuple } from '@accelint/converters/css-rgba';
import { glslToRgba255Tuple } from '@accelint/converters/glsl';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [boolean-to-number](./boolean-to-number/index.md) | Convert boolean values to numeric representations (0/1) |
| [css-rgba](./css-rgba/index.md) | Convert between CSS rgba strings/objects and RGBA 0-255 tuples |
| [glsl](./glsl/index.md) | Convert between GLSL normalized colors (0-1) and RGBA 0-255 tuples |
| [hex](./hex/index.md) | Convert between hex color strings and RGBA 0-255 tuples |
| [to-boolean](./to-boolean/index.md) | Convert various value types to boolean |
| [zxy-to-bbox](./zxy-to-bbox/index.md) | Convert map tile coordinates (z/x/y) to bounding box coordinates |
