## Installation

```bash
pnpm add @accelint/converters
```

## Usage

```typescript
// Import from root (all exports)
import { 
  hexToRgba255Tuple, 
  rgba255TupleToHex,
  booleanToNumber,
  toBoolean 
} from '@accelint/converters';

// Import from sub-modules
import { hexToRgba255Tuple } from '@accelint/converters/hex';
import { cssRgbaStringToRgba255Tuple } from '@accelint/converters/css-rgba';
import { glslToRgba255Tuple } from '@accelint/converters/glsl';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [boolean-to-number](./boolean-to-number) | Convert boolean values to numeric representations (0/1) |
| [css-rgba](./css-rgba) | Convert between CSS rgba strings/objects and RGBA 0-255 tuples |
| [glsl](./glsl) | Convert between GLSL normalized colors (0-1) and RGBA 0-255 tuples |
| [hex](./hex) | Convert between hex color strings and RGBA 0-255 tuples |
| [to-boolean](./to-boolean) | Convert various value types to boolean |
| [zxy-to-bbox](./zxy-to-bbox) | Convert map tile coordinates (z/x/y) to bounding box coordinates |
