# booleanToNumber

Convert a boolean to an integer using bitwise operations.

## Usage

```typescript
import { booleanToNumber } from '@accelint/converters/boolean-to-number';

const one = booleanToNumber(true);
// 1

const zero = booleanToNumber(false);
// 0
```

## Reference

```typescript
function booleanToNumber(val: boolean): number
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `val` | `boolean` | The boolean value to convert to a number. |

### Returns

Returns `1` if `true`, `0` if `false`.

## Examples

### Example: Basic conversion

```typescript
import { booleanToNumber } from '@accelint/converters/boolean-to-number';

console.log(booleanToNumber(true));
// 1

console.log(booleanToNumber(false));
// 0
```

### Example: Array transformation

```typescript
import { booleanToNumber } from '@accelint/converters/boolean-to-number';

const flags = [true, false, true, true, false];
const numbers = flags.map(booleanToNumber);
console.log(numbers);
// [1, 0, 1, 1, 0]
```

### Example: Conditional arithmetic

```typescript
import { booleanToNumber } from '@accelint/converters/boolean-to-number';

function countActive(items: { active: boolean }[]): number {
  return items.reduce((sum, item) => sum + booleanToNumber(item.active), 0);
}

const items = [
  { active: true },
  { active: false },
  { active: true }
];

console.log(countActive(items));
// 2
```

### Example: Bitwise operations

```typescript
import { booleanToNumber } from '@accelint/converters/boolean-to-number';

// Create bit flags
const hasRead = true;
const hasWrite = false;
const hasExecute = true;

const permissions = 
  (booleanToNumber(hasRead) << 2) |
  (booleanToNumber(hasWrite) << 1) |
  booleanToNumber(hasExecute);

console.log(permissions.toString(2).padStart(3, '0'));
// "101"
```

> **Good to know:** This function uses bitwise OR with 0 (`| 0`) for efficient conversion. It's faster than using the ternary operator (`val ? 1 : 0`) or unary plus (`+val`).
