# NTDS

NTDS-compliant library providing SVG icon components and spritesheet constants for rendering tactical military symbols in Common Operating Picture (COP) applications.

## Overview

The `@accelint/ntds` package provides two rendering approaches for NTDS tactical symbols:

1. **React SVG Components** - Individual components for flexible UI integration
2. **Spritesheet Constants** - Numeric IDs for efficient canvas/WebGL rendering

All symbols follow NTDS (Naval Tactical Data System) standards for military tactical displays.

## Installation

```bash
pnpm add @accelint/ntds react react-dom
```

## Quick Start

### Using SVG Components

```tsx
import { SvgAirFriend } from '@accelint/ntds/core/air-friend';
import { NTDS_COLOR_FRIEND } from '@accelint/ntds/constants';

function TacticalIcon() {
  return (
    <SvgAirFriend 
      fill={NTDS_COLOR_FRIEND}
      width={32}
      height={32}
      title="Friendly F-16"
    />
  );
}
```

### Using Spritesheet Constants

```typescript
import { AIR_FRIEND, SURFACE_HOSTILE } from '@accelint/ntds/spritesheets/masked';

// Use sprite IDs with your rendering engine
const friendlyAircraftSprite = spritesheet.getFrame(AIR_FRIEND);

```

## Usage Patterns

### Pattern: Dynamic Entity Rendering

```tsx
import { NTDS_COLOR_FRIEND, NTDS_COLOR_HOSTILE } from '@accelint/ntds/constants';
import { SvgAirFriend } from '@accelint/ntds/core/air-friend';
import { SvgAirHostile } from '@accelint/ntds/core/air-hostile';

type Entity = {
  id: string;
  type: 'air' | 'surface' | 'subsurface';
  affiliation: 'friend' | 'hostile';
  position: { x: number; y: number };
};

function EntityIcon({ entity }: { entity: Entity }) {
  const Component = entity.affiliation === 'friend' 
    ? SvgAirFriend 
    : SvgAirHostile;
    
  const color = entity.affiliation === 'friend'
    ? NTDS_COLOR_FRIEND
    : NTDS_COLOR_HOSTILE;

  return <Component fill={color} title={entity.id} />;
}
```

### Pattern: Tactical Map with Multiple Entities

```tsx
import { SvgAirFriend, SvgSurfaceHostile } from '@accelint/ntds';
import { NTDS_COLOR_FRIEND, NTDS_COLOR_HOSTILE } from '@accelint/ntds/constants';

function TacticalMap({ entities }) {
  return (
    <svg width={800} height={600} viewBox="0 0 800 600">
      {entities.map((entity) => (
        <g 
          key={entity.id} 
          transform={`translate(${entity.x}, ${entity.y})`}
        >
          {entity.type === 'air' && entity.affiliation === 'friend' && (
            <SvgAirFriend fill={NTDS_COLOR_FRIEND} />
          )}
          {entity.type === 'surface' && entity.affiliation === 'hostile' && (
            <SvgSurfaceHostile fill={NTDS_COLOR_HOSTILE} />
          )}
        </g>
      ))}
    </svg>
  );
}
```

### Pattern: Spritesheet Rendering for Performance

```typescript
import { AIR_FRIEND, SURFACE_HOSTILE } from '@accelint/ntds/spritesheets/masked';

class HighPerformanceCop {
  private spritesheet: HTMLImageElement;
  private spriteData: SpritesheetData;

  renderEntities(entities: Entity[], ctx: CanvasRenderingContext2D): void {
    for (const entity of entities) {
      const spriteId = this.getSpriteId(entity);
      const sprite = this.spriteData.frames[spriteId];
      
      ctx.drawImage(
        this.spritesheet,
        sprite.frame.x,
        sprite.frame.y,
        sprite.frame.w,
        sprite.frame.h,
        entity.x,
        entity.y,
        24,
        24
      );
    }
  }
}
```

## Performance Considerations

**Use SVG Components when:**
- Building React UIs with moderate entity counts (< 100 entities)
- Need interactive icons with hover states, clicks
- Styling flexibility is important
- Accessibility features (titles, ARIA labels) are required

**Use Spritesheet Constants when:**
- Rendering hundreds or thousands of entities
- Building canvas/WebGL-based tactical displays
- Performance is critical
- COP or real-time tracking applications

### Example: Interactive Selectable Entity

```tsx
import { useState } from 'react';
import { SvgHelicopterFriend } from '@accelint/ntds/core/helicopter-friend';
import { NTDS_COLOR_FRIEND } from '@accelint/ntds/constants';

function SelectableEntity({ entity, onSelect }) {
  const [isHovered, setIsHovered] = useState(false);

  return (
    <SvgHelicopterFriend
      fill={isHovered ? '#00A0FF' : NTDS_COLOR_FRIEND}
      width={32}
      height={32}
      title={entity.callsign}
      onClick={() => onSelect(entity)}
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      style={{ 
        cursor: 'pointer', 
        transition: 'fill 0.2s',
      }}
    />
  );
}
```

## Contributing

This package is generated from NTDS-compliant SVG source files using the `smeegl` tool. To add new symbols:

1. Add SVG files to `packages/ntds/icons/core/` or `packages/ntds/icons/masked/`
2. Run `pnpm build` to regenerate components and spritesheet
3. Run `pnpm index` to update package exports
