## Installation

```bash
pnpm add @accelint/constants
```

## Usage

```typescript
// Import from root (all exports)
import { 
  CSS_RGBA_LEGACY_REGEX, 
  DEFAULT_COORDINATE,
  DISTANCE_UNIT_SYMBOLS 
} from '@accelint/constants';

// Import from sub-modules
import { HEX_REGEX } from '@accelint/constants/color';
import { DISTANCE_UNIT_BY_SYMBOL } from '@accelint/constants/units';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [color](./color) | Regular expressions for validating CSS rgba() and hex color formats |
| [coordinates](./coordinates) | Default empty coordinate value using NaN to avoid "Null Island" at [0,0] |
| [units](./units) | SI-compliant display symbols for distance units and bidirectional mapping |
