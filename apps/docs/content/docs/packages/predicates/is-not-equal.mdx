Creates a predicate that determines if a value is **not** strictly equal to a reference value.

## Reference

```typescript
function isNotEqual<T>(reference: T): (value: T) => boolean
```

## Examples

```typescript
import { isNotEqual } from '@accelint/predicates';

const isNotZero = isNotEqual(0);
isNotZero(5);  // true
isNotZero(0);  // false

// Removing null values
const values = [1, null, 2, null, 3];
const nonNull = values.filter(isNotEqual(null)); // [1, 2, 3]
```

> **Good to know:** This uses strict inequality (`!==`). For filtering arrays, this is more efficient than using `!isEqual(x)`.
