# Boolean-like Value Predicates

Case-insensitive predicates for testing boolean-like string and numeric values. Useful for parsing configuration files, form inputs, and API responses.

## Usage

```typescript
import {
  isTrue,
  isFalse,
  isYes,
  isNo,
  isOn,
  isOff,
  isAnyTruthy,
  isAnyFalsy
} from '@accelint/predicates/is-noyes';

isTrue(1);          // true
isTrue('true');     // true
isYes('yes');       // true
isOn('on');         // true

isFalse(0);         // true
isFalse('false');   // true
isNo('no');         // true
isOff('off');       // true

isAnyTruthy('yes'); // true
isAnyFalsy('off');  // true
```

## Value Lists

### True Values
`['1', 'true']`

### False Values
`['', '0', 'false', 'nan', 'null', 'undefined']`

### Yes Values
`['y', 'yes', '1', 'true']`

### No Values  
`['n', 'no', '', '0', 'false', 'nan', 'null', 'undefined']`

### On Values
`['on', '1', 'true']`

### Off Values
`['off', '', '0', 'false', 'nan', 'null', 'undefined']`

## Real-World Examples

### Example: Parsing environment variables

```typescript
import { isAnyTruthy } from '@accelint/predicates/is-noyes';

const DEBUG = process.env.DEBUG;
const isDebugMode = isAnyTruthy(DEBUG);

if (isDebugMode) {
  console.log('Debug mode enabled');
}

// Works with: DEBUG=1, DEBUG=true, DEBUG=yes, DEBUG=on
```

### Example: Feature flag validation

```typescript
import { isOn, isOff } from '@accelint/predicates/is-noyes';

interface FeatureFlags {
  newUI: string;
  betaFeatures: string;
}

function parseFeatureFlags(flags: FeatureFlags) {
  return {
    newUI: isOn(flags.newUI),
    betaFeatures: isOn(flags.betaFeatures)
  };
}

const flags = parseFeatureFlags({ newUI: 'on', betaFeatures: 'off' });
// { newUI: true, betaFeatures: false }
```

### Example: Form checkbox parsing

```typescript
import { isYes, isNo } from '@accelint/predicates/is-noyes';

function parseFormData(data: Record<string, string>) {
  return {
    newsletter: isYes(data.newsletter),
    notifications: !isNo(data.notifications)
  };
}

const form = { newsletter: 'yes', notifications: '' };
const parsed = parseFormData(form);
// { newsletter: true, notifications: false }
```

> **Good to know:** All comparisons are case-insensitive and trim whitespace. These predicates are more lenient than `toBoolean` from `@accelint/converters` — use converters for strict boolean coercion.
