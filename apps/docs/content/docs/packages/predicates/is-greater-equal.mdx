Creates a predicate that determines if a value is greater than or equal to a threshold.

## Reference

```typescript
function isGreaterEqual<T extends number | string>(threshold: T): (value: T) => boolean
```

## Examples

```typescript
import { isGreaterEqual } from '@accelint/predicates';

const isAtLeast18 = isGreaterEqual(18);
isAtLeast18(21); // true
isAtLeast18(18); // true (inclusive)
isAtLeast18(16); // false

// Passing grade filter
const scores = [45, 78, 92, 65, 88];
const passing = scores.filter(isGreaterEqual(70)); // [78, 92, 88]
```

### Combined Example: Range Validation

```typescript
import { isGreaterEqual, isLesserEqual } from '@accelint/predicates';
import { andFn } from '@accelint/core';

// Create a range validator by composing predicates
const isBetween0And100 = andFn(
  isGreaterEqual(0),
  isLesserEqual(100)
);

isBetween0And100(50);  // true
isBetween0And100(150); // false
isBetween0And100(-10); // false
```

> **Good to know:** The threshold is inclusive. Use `isGreater` for exclusive comparison.
