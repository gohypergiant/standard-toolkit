# isGreater

Creates a predicate that determines if a value is greater than a threshold.

## Reference

```typescript
function isGreater<T extends number | string>(threshold: T): (value: T) => boolean
```

## Examples

```typescript
import { isGreater } from '@accelint/predicates';

const isGreaterThan10 = isGreater(10);
isGreaterThan10(15); // true
isGreaterThan10(5);  // false

// String comparison (lexicographic)
const isAfterM = isGreater('M');
isAfterM('Z'); // true
isAfterM('A'); // false

// Array filtering
const numbers = [1, 5, 10, 15, 20];
const greaterThan10 = numbers.filter(isGreater(10)); // [15, 20]
```

> **Good to know:** String comparisons use lexicographic ordering. For case-insensitive comparisons, convert strings to the same case before applying predicates.
