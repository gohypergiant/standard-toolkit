# String Start/End Predicates

Curried predicate functions for testing if strings start or end with specific substrings. All functions are case-sensitive and use native String methods internally.

## Usage

```typescript
import {
  doesStartWith,
  doesEndWith,
  doesNotStartWith,
  doesNotEndWith
} from '@accelint/predicates';

const isHttpUrl = doesStartWith('http');
isHttpUrl('https://example.com'); // true
isHttpUrl('ftp://example.com');   // false

const isJsFile = doesEndWith('.js');
isJsFile('app.js');   // true
isJsFile('style.css'); // false
```

## doesStartWith

Creates a predicate function that determines if a string starts with a specific prefix.

### Reference

```typescript
function doesStartWith(prefix: string): (input: string) => boolean
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `prefix` | `string` | The substring to use as the prefix |

#### Returns

Curried function that accepts a string and returns `true` if it starts with the prefix.

### Examples

#### Example: URL validation

```typescript
import { doesStartWith } from '@accelint/predicates';

const isHttps = doesStartWith('https://');
const isHttp = doesStartWith('http://');

function isSecureUrl(url: string): boolean {
  return isHttps(url);
}

isSecureUrl('https://example.com'); // true
isSecureUrl('http://example.com');  // false
```

#### Example: Filtering file paths

```typescript
import { doesStartWith } from '@accelint/predicates';

const paths = [
  '/home/user/documents',
  '/var/log/system',
  '/home/user/downloads',
  '/etc/config'
];

const userPaths = paths.filter(doesStartWith('/home/user'));
// ['/home/user/documents', '/home/user/downloads']
```

## doesEndWith

Creates a predicate function that determines if a string ends with a specific suffix.

### Reference

```typescript
function doesEndWith(suffix: string): (input: string) => boolean
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `suffix` | `string` | The substring to use as the suffix |

#### Returns

Curried function that accepts a string and returns `true` if it ends with the suffix.

### Examples

#### Example: File extension filtering

```typescript
import { doesEndWith } from '@accelint/predicates';

const isImageFile = doesEndWith('.jpg');
const isConfigFile = doesEndWith('.json');

const files = ['avatar.jpg', 'config.json', 'script.js', 'photo.jpg'];
const images = files.filter(doesEndWith('.jpg'));
// ['avatar.jpg', 'photo.jpg']
```

#### Example: Email domain validation

```typescript
import { doesEndWith } from '@accelint/predicates';

const isCompanyEmail = doesEndWith('@company.com');

function validateEmail(email: string): boolean {
  return isCompanyEmail(email);
}

validateEmail('user@company.com');    // true
validateEmail('user@external.com');   // false
```

## doesNotStartWith

Creates a predicate function that determines if a string does **not** start with a specific prefix.

### Reference

```typescript
function doesNotStartWith(prefix: string): (input: string) => boolean
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `prefix` | `string` | The substring to use as the prefix |

#### Returns

Curried function that accepts a string and returns `true` if it does **not** start with the prefix.

### Examples

#### Example: Excluding system files

```typescript
import { doesNotStartWith } from '@accelint/predicates';

const isNotHidden = doesNotStartWith('.');
const files = ['.git', '.env', 'README.md', '.gitignore', 'src'];
const visible = files.filter(isNotHidden);
// ['README.md', 'src']
```

## doesNotEndWith

Creates a predicate function that determines if a string does **not** end with a specific suffix.

### Reference

```typescript
function doesNotEndWith(suffix: string): (input: string) => boolean
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `suffix` | `string` | The substring to use as the suffix |

#### Returns

Curried function that accepts a string and returns `true` if it does **not** end with the suffix.

### Examples

#### Example: Excluding backup files

```typescript
import { doesNotEndWith } from '@accelint/predicates';

const isNotBackup = doesNotEndWith('.bak');
const files = ['data.json', 'data.json.bak', 'config.yaml', 'config.yaml.bak'];
const active = files.filter(isNotBackup);
// ['data.json', 'config.yaml']
```

> **Good to know:** All comparisons are case-sensitive. Use native String methods like `.toLowerCase()` before applying these predicates if case-insensitive matching is needed.
