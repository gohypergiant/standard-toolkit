## Installation

```bash
pnpm add @accelint/formatters
```

## Usage

```typescript
// Import from root (all exports)
import { formatBearing, formatDistance, formatM3A } from '@accelint/formatters';

// Import from sub-modules
import { formatBearing, formatDistance } from '@accelint/formatters/bearing';
import { formatM1 } from '@accelint/formatters/iff';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [bearing](./bearing.md) | Format tactical bearing readouts as zero-padded degrees and distances in meters with SI unit symbols |
| [iff](./iff/index.md) | Format IFF (Identification Friend or Foe) transponder mode codes with proper zero-padding |
