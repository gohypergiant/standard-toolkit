## Installation

```bash
pnpm add @accelint/formatters
```

## Usage

```typescript
// Import from root (all exports)
import { formatM1, formatM2, formatM3A, formatM4, formatM5 } from '@accelint/formatters';

// Import from sub-modules
import { formatM1 } from '@accelint/formatters/iff';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [iff](./iff/index.md) | Format IFF (Identification Friend or Foe) transponder mode codes with proper zero-padding |
