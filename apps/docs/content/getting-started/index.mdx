# Getting Started

Welcome to Standard Toolkit - a collection of 29 production-ready packages for building modern web applications.

## Quick Start

Install any package from the toolkit:

```bash
pnpm add @hypergiant/logger
```

## Available Packages

Standard Toolkit is organized into three sections:

### Toolkits
Large, integrated libraries for complex domains:
- **design-foundation**: Design token system and Tailwind utilities
- **design-toolkit**: React component library built on React Aria
- **map-toolkit**: Comprehensive geospatial library with coordinate systems and projections

### Packages
Focused utilities for common development needs:
- **bus**: Event bus for pub/sub messaging
- **constants**: Common constants and enums
- **core**: Core utilities and helpers
- **dataset**: Data manipulation utilities
- **formatters**: String and number formatters
- **geo**: Geospatial utilities and coordinate operations
- **hotkey-manager**: Keyboard shortcut management
- **icons**: SVG icon components
- **logger**: Structured logging utility
- **math**: Mathematical operations and utilities
- **ntds**: National Transit Database Standard utilities
- **predicates**: Type guards and validation predicates
- **temporal**: Date and time utilities
- **web-worker**: Web Worker utilities
- **websocket**: WebSocket client utilities

### Tooling
Configuration packages for build tools and linters:
- **postcss-tailwind-css-modules**: PostCSS plugin for Tailwind CSS Modules
- **biome-config**: Shared Biome configuration
- **eslint-config**: Shared ESLint configuration
- **prettier-config**: Shared Prettier configuration
- **smeegl**: Monorepo management utilities
- **typescript-config**: Shared TypeScript configurations
- **vitest-config**: Shared Vitest configuration

## Installation

All packages are published to npm under the `@hypergiant` scope. Install any package using pnpm:

```bash
pnpm add @hypergiant/package-name
```

For multiple packages:

```bash
pnpm add @hypergiant/logger @hypergiant/math @hypergiant/core
```
