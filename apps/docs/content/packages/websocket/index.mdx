# WebSocket

A robust WebSocket client implementation with automatic reconnection, message queuing, and type-safe event handling.

## Installation

```bash
pnpm add @accelint/websocket
```

## Features

- Automatic reconnection with exponential backoff
- Message queuing during disconnection
- Type-safe message handling
- Connection state management
- Full TypeScript support
