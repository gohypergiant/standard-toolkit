# Web Worker

Utilities for creating and managing Web Workers to offload heavy computation to background threads.

## Installation

```bash
pnpm add @accelint/web-worker
```

## Features

- Simplified Web Worker API
- Type-safe message passing
- Worker pool management
- Promise-based interface
- Full TypeScript support
