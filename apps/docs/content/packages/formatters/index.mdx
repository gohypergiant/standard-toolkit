# Formatters

A collection of formatting utilities for strings, numbers, dates, and other data types.

## Installation

```bash
pnpm add @accelint/formatters
```

## Features

- Number formatting (currency, percentages, decimals)
- String formatting and templating
- Date and time formatting
- Unit conversion and display
- Full TypeScript support
