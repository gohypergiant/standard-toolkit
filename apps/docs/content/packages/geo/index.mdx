# Geo

A collection of JavaScript functions for working with coordinates and geospatial data.

## Installation

```bash
pnpm add @accelint/geo
```

## Usage

```typescript
// Import coordinate utilities
import { createCoordinate, coordinateSystems } from '@accelint/geo';

// Import formatters and parsers
import { formatDecimalDegrees, parseDecimalDegrees } from '@accelint/geo';
import { parseMGRS, parseUTM } from '@accelint/geo';
```

## Available Exports

| Export Path | Description |
|-------------|-------------|
| [coordinates/coordinate](./coordinates/coordinate.md) | Parse, validate, convert, and format geographic coordinates across multiple notation systems |
| [coordinates/latlon/decimal-degrees](./coordinates/latlon/decimal-degrees/) | Format and parse latitude/longitude in decimal degrees notation |
| [coordinates/latlon/degrees-decimal-minutes](./coordinates/latlon/degrees-decimal-minutes/) | Format and parse coordinates in degrees decimal minutes notation |
| [coordinates/latlon/degrees-minutes-seconds](./coordinates/latlon/degrees-minutes-seconds/) | Format and parse coordinates in degrees minutes seconds notation |
| [coordinates/mgrs/parser](./coordinates/mgrs/parser.md) | Parse Military Grid Reference System (MGRS) coordinate strings |
| [coordinates/utm/parser](./coordinates/utm/parser.md) | Parse Universal Transverse Mercator (UTM) coordinate strings |
