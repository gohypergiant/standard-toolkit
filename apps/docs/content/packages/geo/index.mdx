# Geo

Geospatial utilities for coordinate operations, distance calculations, and geographic data manipulation.

## Installation

```bash
pnpm add @accelint/geo
```

## Features

- Coordinate transformation utilities
- Distance and bearing calculations
- GeoJSON utilities
- Bounding box operations
- Full TypeScript support
