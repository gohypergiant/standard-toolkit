# Hotkey Manager

A flexible keyboard shortcut management system for web applications with conflict detection and platform-aware shortcuts.

## Installation

```bash
pnpm add @accelint/hotkey-manager
```

## Features

- Cross-platform hotkey support (Mac/Windows/Linux)
- Conflict detection and resolution
- Hotkey scope management
- TypeScript support with type-safe shortcut definitions
- React hooks for easy integration
