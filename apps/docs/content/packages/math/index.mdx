# Math

A collection of mathematical operations and utilities for numerical computing, including statistics, interpolation, and geometric calculations.

## Installation

```bash
pnpm add @accelint/math
```

## Features

- Statistical functions (mean, median, mode, standard deviation)
- Interpolation (linear, cubic, spline)
- Geometric calculations
- Vector and matrix operations
- Full TypeScript support
