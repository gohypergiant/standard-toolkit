# Logger

A flexible and extensible logging utility with callsite tracking, environment awareness, and structured logging support.

## Installation

```bash
pnpm add @accelint/logger
```

## Features

- Structured logging with context
- Callsite tracking for debugging
- Environment-aware log levels
- Custom transport support
- TypeScript support with typed log methods
