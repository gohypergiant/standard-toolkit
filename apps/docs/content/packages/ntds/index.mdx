# NTDS

Utilities for working with National Transit Database Standard (NTDS) data formats and schemas.

## Installation

```bash
pnpm add @accelint/ntds
```

## Features

- NTDS data format parsing and validation
- Schema definitions and type guards
- Data transformation utilities
- Full TypeScript support
