# NTDS SVG Icon Components

React SVG icon components representing NTDS (Naval Tactical Data System) tactical symbols for military entities. Each component renders a 24×24 SVG with customizable fill color and accessibility support.

## Usage

```tsx
import { SvgAirFriend } from '@accelint/ntds/core/air-friend';
import { NTDS_COLOR_FRIEND } from '@accelint/ntds/constants';

function TacticalDisplay() {
  return (
    <SvgAirFriend 
      fill={NTDS_COLOR_FRIEND}
      width={32}
      height={32}
      title="Friendly Aircraft"
    />
  );
}
```

## Reference

All NTDS SVG components share a common interface:

```typescript
interface Props {
  title?: string;
  titleId?: string;
}

type SvgComponent = (props: SVGProps<SVGSVGElement> & Props) => JSX.Element;
```

### Props

| Prop | Type | Default | Required |
|------|------|---------|----------|
| `fill` | `string` | `#FF69B4` | No |
| `width` | `number \| string` | `24` | No |
| `height` | `number \| string` | `24` | No |
| `title` | `string` | - | No |
| `titleId` | `string` | - | No |
| `className` | `string` | - | No |
| `style` | `CSSProperties` | - | No |

#### `fill`

Color value for the SVG path fills. Defaults to hot pink (`#FF69B4`) as a visual indicator that fill should be explicitly set.

Use with NTDS color constants for proper affiliation colors:
- `NTDS_COLOR_FRIEND` - Blue for friendly entities
- `NTDS_COLOR_HOSTILE` - Red for hostile entities
- `NTDS_COLOR_UNKNOWN` - Yellow for unknown entities
- And other NTDS standard colors

#### `title`

Accessible title for screen readers. When provided, the SVG element includes an `aria-labelledby` attribute referencing the title.

> **Good to know:** Always provide a `title` prop when the icon conveys important information, especially in interactive contexts.

#### `titleId`

Custom ID for the `<title>` element. Defaults to automatic ID generation if not provided. Useful for ensuring unique IDs when multiple instances exist on the page.

### Inherited Props

All components accept standard SVGSVGElement props including:
- `className` - CSS class name
- `style` - Inline styles
- `onClick` - Click handler
- `onMouseEnter` / `onMouseLeave` - Mouse events
- `aria-*` - Additional ARIA attributes

## Examples

### Example: Entity with standard color

```tsx
import { SvgAirFriend } from '@accelint/ntds/core/air-friend';
import { NTDS_COLOR_FRIEND } from '@accelint/ntds/constants';

function FriendlyAircraft() {
  return (
    <SvgAirFriend 
      fill={NTDS_COLOR_FRIEND}
      title="Friendly F-16"
    />
  );
}
```

### Example: Dynamic affiliation rendering

```tsx
import { NTDS_COLOR_FRIEND, NTDS_COLOR_HOSTILE } from '@accelint/ntds/constants';
import { SvgAirFriend } from '@accelint/ntds/core/air-friend';
import { SvgAirHostile } from '@accelint/ntds/core/air-hostile';

type Entity = {
  id: string;
  affiliation: 'friend' | 'hostile';
};

function EntityIcon({ entity }: { entity: Entity }) {
  if (entity.affiliation === 'hostile') {
    return (
      <SvgAirHostile 
        fill={NTDS_COLOR_HOSTILE}
        title={`Hostile aircraft ${entity.id}`}
      />
    );
  }
  
  return (
    <SvgAirFriend 
      fill={NTDS_COLOR_FRIEND}
      title={`Friendly aircraft ${entity.id}`}
    />
  );
}
```

### Example: Interactive icon with events

```tsx
import { SvgHelicopterFriend } from '@accelint/ntds/core/helicopter-friend';
import { NTDS_COLOR_FRIEND } from '@accelint/ntds/constants';

function InteractiveHelicopter({ onSelect }) {
  const [isHovered, setIsHovered] = useState(false);

  return (
    <SvgHelicopterFriend
      fill={isHovered ? '#00A0FF' : NTDS_COLOR_FRIEND}
      width={32}
      height={32}
      title="Helicopter Unit 12"
      onClick={onSelect}
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      style={{ cursor: 'pointer', transition: 'fill 0.2s' }}
    />
  );
}
```

### Example: Multiple entities on tactical map

```tsx
import { SvgAirFriend } from '@accelint/ntds/core/air-friend';
import { SvgSurfaceHostile } from '@accelint/ntds/core/surface-hostile';
import { SvgSubSurfaceUnknown } from '@accelint/ntds/core/sub-surface-unknown';
import {
  NTDS_COLOR_FRIEND,
  NTDS_COLOR_HOSTILE,
  NTDS_COLOR_UNKNOWN,
} from '@accelint/ntds/constants';

function TacticalMap({ entities }) {
  return (
    <svg width={800} height={600}>
      {entities.map((entity) => {
        const Icon = getIconComponent(entity.type, entity.affiliation);
        const color = getAffiliationColor(entity.affiliation);
        
        return (
          <g key={entity.id} transform={`translate(${entity.x}, ${entity.y})`}>
            <Icon 
              fill={color}
              title={entity.callsign}
            />
          </g>
        );
      })}
    </svg>
  );
}
```
