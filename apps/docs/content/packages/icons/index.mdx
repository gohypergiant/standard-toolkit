# Icons

A collection of SVG icon components for React applications with consistent sizing and styling.

## Installation

```bash
pnpm add @accelint/icons
```

## Features

- Optimized SVG icons
- Consistent sizing and styling API
- Tree-shakeable imports
- TypeScript support
- Accessible by default
