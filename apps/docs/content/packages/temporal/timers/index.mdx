# Clock-Aligned Timers

Provides drop-in replacements for `setTimeout` and `setInterval` that align callback execution to clock second boundaries. Useful for animations, polling, and time-based UI updates that need to stay synchronized with wall-clock time.

## setClockInterval

Executes a callback repeatedly at a specified interval, starting at the next clock second boundary.

### Usage

```typescript
import { setClockInterval } from '@accelint/temporal/timers';

const cleanup = setClockInterval(() => {
  console.log('Tick:', new Date().toISOString());
}, 1000);

// Later, stop the interval
cleanup();
```

### Reference

```typescript
function setClockInterval(
  cb: () => void,
  ms: number
): () => void
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `cb` | `() => void` | Callback function to execute immediately at the next clock second, then repeatedly after each interval. |
| `ms` | `number` | Time in milliseconds between callback executions. |

#### Returns

Returns a cleanup function that clears the interval when called.

### Examples

#### Example: Updating a clock display

```typescript
import { setClockInterval } from '@accelint/temporal/timers';

function updateClock(element: HTMLElement) {
  const cleanup = setClockInterval(() => {
    element.textContent = new Date().toLocaleTimeString();
  }, 1000);
  
  return cleanup;
}

const cleanup = updateClock(document.getElementById('clock'));
// Updates every second, synchronized to system clock
```

#### Example: Polling API with drift correction

```typescript
import { setClockInterval } from '@accelint/temporal/timers';

async function pollEndpoint(url: string) {
  const cleanup = setClockInterval(async () => {
    try {
      const response = await fetch(url);
      const data = await response.json();
      console.log('Polled data:', data);
    } catch (error) {
      console.error('Poll failed:', error);
    }
  }, 5000);
  
  return cleanup;
}

const cleanup = await pollEndpoint('/api/status');
// Polls every 5 seconds, correcting for any execution drift
```

#### Example: Animation frame synchronization

```typescript
import { setClockInterval } from '@accelint/temporal/timers';

function animateCounter(element: HTMLElement, interval: number) {
  let count = 0;
  
  const cleanup = setClockInterval(() => {
    count++;
    element.textContent = String(count);
  }, interval);
  
  return cleanup;
}

const cleanup = animateCounter(document.getElementById('counter'), 250);
// Increments counter every 250ms, aligned to clock boundaries
```

> **Good to know:** The first callback execution happens at the next clock second boundary, not immediately. The interval automatically corrects for drift by recalculating the delay on each iteration using the `remainder` function.

## setClockTimeout

Executes a callback once after a specified delay, starting from the next clock second boundary.

### Usage

```typescript
import { setClockTimeout } from '@accelint/temporal/timers';

const cleanup = setClockTimeout(() => {
  console.log('Executed at:', new Date().toISOString());
}, 5000);

// Cancel if needed before execution
cleanup();
```

### Reference

```typescript
function setClockTimeout(
  cb: () => void,
  ms: number
): () => void
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `cb` | `() => void` | Callback function to execute after the delay. |
| `ms` | `number` | Time in milliseconds to wait before executing the callback. |

#### Returns

Returns a cleanup function that cancels the timeout when called.

### Examples

#### Example: Delayed notification

```typescript
import { setClockTimeout } from '@accelint/temporal/timers';

function showNotification(message: string, delay: number) {
  const cleanup = setClockTimeout(() => {
    alert(message);
  }, delay);
  
  return cleanup;
}

const cancel = showNotification('Time is up!', 10000);
// Shows notification after 10 seconds, starting at next clock second

// User can cancel before it fires
document.getElementById('cancel').addEventListener('click', cancel);
```

#### Example: Debounced action with clock alignment

```typescript
import { setClockTimeout } from '@accelint/temporal/timers';

function debouncedSave(data: unknown) {
  let cleanup: (() => void) | undefined;
  
  return () => {
    if (cleanup) cleanup();
    
    cleanup = setClockTimeout(() => {
      console.log('Saving:', data);
      // Perform save operation
    }, 2000);
    
    return cleanup;
  };
}

const save = debouncedSave({ value: 42 });
const cleanup = save();
// Will save 2 seconds after the next clock second
```

#### Example: Scheduled task execution

```typescript
import { setClockTimeout } from '@accelint/temporal/timers';

async function scheduleTask(taskFn: () => Promise<void>, delayMs: number) {
  const cleanup = setClockTimeout(async () => {
    try {
      await taskFn();
      console.log('Task completed');
    } catch (error) {
      console.error('Task failed:', error);
    }
  }, delayMs);
  
  return cleanup;
}

const cleanup = await scheduleTask(
  async () => {
    await fetch('/api/cleanup');
  },
  60000
);
// Executes cleanup task 1 minute after next clock second
```

> **Good to know:** Like `setClockInterval`, the execution starts counting from the next clock second boundary. For immediate execution use standard `setTimeout`. Zero or negative delays are treated as immediate execution after reaching the next clock second.
