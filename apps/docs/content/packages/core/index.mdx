# Core

Essential core utilities and helper functions for TypeScript applications.

## Installation

```bash
pnpm add @accelint/core
```

## Features

- Function utilities (compose, pipe, memoize)
- Object manipulation helpers
- Array utilities
- Type guards and assertions
- Full TypeScript support
