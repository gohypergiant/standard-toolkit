# Predicates

A collection of type guards and validation predicates for runtime type checking in TypeScript.

## Installation

```bash
pnpm add @accelint/predicates
```

## Features

- Comprehensive type guard library
- Composable predicate functions
- Runtime validation utilities
- Full TypeScript support with type narrowing
- Zero dependencies
