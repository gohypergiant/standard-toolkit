# Constants

A collection of common constants, enums, and utility values used across applications.

## Installation

```bash
pnpm add @accelint/constants
```

## Features

- HTTP status codes and methods
- Common regex patterns
- Time and date constants
- Unit conversion factors
- Full TypeScript support with const assertions
