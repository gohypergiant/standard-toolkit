# Design Foundation

Design Foundation provides a comprehensive design token system and Tailwind CSS utilities for building consistent user interfaces.

## Installation

```bash
pnpm add @hypergiant/design-foundation
```

## Features

- Design token system with semantic color, typography, and spacing tokens
- Tailwind CSS plugin for design token integration
- CSS custom properties for theme customization
- Light and dark mode support
